プライバシーポリシー

「マイジャーナル」（以下、本アプリ）は、個人用の日記アプリです。本アプリにおけるデータの取り扱いを以下のとおり定めます。

1. 保存されるデータ

日記の本文、気分、天気、歩数、体重、写真は、ご利用の端末のブラウザ内（IndexedDB）に保存されます。開発者のサーバーにこれらのデータが送信・保存されることはありません。

2. Googleドライブ連携

ユーザーが連携を選んだ場合に限り、Googleドライブの権限（drive.file）を使い、本アプリが作成したフォルダ内に日記のCSVと写真を保存・読み込みします。本アプリが作成したファイル以外にはアクセスしません。

3. Googleヘルス連携

ユーザーが連携を選んだ場合に限り、歩数と体重（読み取り専用）をGoogleヘルスから取得し、日記に表示します。取得したデータは端末内およびユーザー自身のGoogleドライブにのみ保存されます。

4. 位置情報と天気

天気の取得のため、端末の位置情報（許可した場合のみ）を天気サービス（Open-Meteo）に送信します。許可しない場合は、品川付近の天気を表示します。位置情報は保存しません。

5. Google API サービスのユーザーデータの取り扱い

本アプリによるGoogle APIから受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに準拠します。取得したデータは、日記の表示・保存の目的以外には使用せず、第三者への提供、広告への利用、販売は行いません。

6. データの削除

端末内のデータは、ブラウザのサイトデータを削除することで消去できます。連携を解除するには、Googleアカウントの「サードパーティのアクセス」から本アプリを削除してください。Googleドライブ上のファイルはユーザー自身で削除できます。

7. 改定

本ポリシーは必要に応じて改定することがあります。
